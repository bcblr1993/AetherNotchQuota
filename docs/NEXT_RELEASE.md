# 下一版：可靠的额度助手，有趣的小伙伴

本轮是本地开发候选版，不代表已发布。版本仍由 VERSION 管理；正式版本号、签名、公证、官网和升级验收在发布任务中处理。

## 本轮范围

- [x] 三位主角采用用户确认的软萌绘本方案：小龟慢探、小狐蹭蹭、小幽灵害羞团团；摸摸后延迟浮出小爱心。
- [x] 将 SoftCompanion 插画动画接入实际侧栏，恢复独立动画预览入口，保留单击互动、双击额度和拖拽。
- [x] 原生设置窗口：显示与伙伴、账号、额度通知、更新与脱敏诊断。
- [x] 可选低额度（20% / 10%）和恢复通知、账号静音、安静时段；默认关闭，用户开启时才请求通知权限。
- [x] 限流 Retry-After 与失败退避；仍只查询已选账号，成功后恢复常规节奏。
- [x] 最终单元测试、构建、包检查、原生 UI smoke 与动画截图检查。
- [x] 更新文档与验收记录。

## 验收边界

模拟测试不读取登录、不发额度或通知请求，不修改用户设置；不退出用户的其他应用。真实系统通知投递、长期睡眠唤醒、显示器热插拔和默认安全策略下的正式版升级需要另行实机验收，不能用自动测试替代。

## 后续按需求决定

本地历史、更多服务、云同步和更多角色不包含在本轮；优先保持轻量、账号隔离和低打扰。公开发布必须执行项目规定的签名公证、升级验收和磁盘清理。

设置与提醒的首轮验收见 [本地验收记录](COMPANION_SETTINGS_VALIDATION.md)；最终动画见 [绘本动画验收](SOFT_COMPANION_VALIDATION.md)。
