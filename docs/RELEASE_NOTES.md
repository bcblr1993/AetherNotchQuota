# AetherNotchQuota 0.1.26 · 熊猫桌宠首版

糯米熊猫采用柔光立体 C 风格，首次加入拿杯喝水、戴上耳机听音乐两段完整动作。

## 使用方法

1. 右键 → 设置与更新 → 显示模式 → 侧边栏。
2. 在“收起外观”中选择“糯米熊猫”，将侧栏拖离屏幕边缘，等待收起。
3. 单击熊猫交替播放喝水和听音乐；双击展开额度列表。右键设置里也可选择“陪熊猫玩（拖出侧栏后）”。
4. “熊猫日常动作”默认启用；空闲时播放一段动作，随后保留约 35 秒安静间隔，可随时关闭。

## 范围与性能

- 本版只升级熊猫，其他八位小伙伴保留 0.1.25 外观。
- 吃竹子、睡觉等其他 C 风格日常尚未加入；这是首个可体验版本。
- 使用预绘制全身帧和有限时长的原生动画，静止不运行帧计时器；尊重减少动态效果、低电量、隐藏及休眠。
- 互动读取现有额度缓存，不额外查询账号；已有账号选择、侧栏位置和自动轮换设置保留。

需要 Apple Silicon Mac、macOS 13 或更高版本。
