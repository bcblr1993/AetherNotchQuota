# AetherNotchQuota 0.1.27 · 小乌龟的桌面日常

抹茶小龟现在会自己活动：散步、回家缩壳休息、翻书、低头喝水，以及去河里游泳。

## 使用方法

1. 右键 → 设置与更新 → 显示模式 → 侧边栏，在“收起外观”选择“抹茶小龟”。
2. 把它拖离屏幕边缘，等待收起；自动日常默认开启，动作之间休息 10–18 秒。
3. 单击触发下一项日常，双击查看额度；右键可直接选择动作或关闭“乌龟自动日常”。

## 动作与交互

- 散步会真实移动桌面小窗口，活动限制在放置位置附近，保持在当前显示器内。
- 回家先爬回放置点，再缩进龟壳打盹；拖动会重新设定放置点。
- 阅读包含翻页，喝水包含伸脖子、低头和抬头。
- 游泳先爬到河边，下水划动、转身上岸，再返回出发位置。河岸场景在动作期间显现。
- 悬停、拖动、查看额度、隐藏和休眠会停止动作；支持减少动态效果及低电量模式。
- 熊猫保留喝水、听音乐互动，其他伙伴维持已有外观和行为。

## 性能与兼容

- 静止不运行逐帧计时器；仅爬行时使用窗口移动计时器。最多缓存两段动作，解码图像上限约 8.25 MiB。
- 日常互动读取额度缓存，不增加额度查询，不修改已保存的摆放位置和账号偏好。
- 65 项单元测试、UI 与桌宠场景检查通过。需要 Apple Silicon Mac、macOS 13 或更高版本。
