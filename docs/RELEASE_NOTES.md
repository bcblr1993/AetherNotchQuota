AetherNotchQuota 0.1.23：支持简体中文、英文和日文。

- 新增「设置与更新 → 语言」，支持跟随系统及手动切换，未支持的系统语言回退到英文。
- 国际化菜单、额度详情、账号管理、宠物提醒、错误提示和辅助功能文字；日期时间按所选语言显示。
- 切换语言立即更新应用界面并保存偏好，保留账号、别名、顺序和额度缓存，不额外查询额度。系统文件选择器和 Sparkle 自带弹窗在下次启动后使用所选语言。
- 新增三语 UI 自动检查与语言资源打包检查。

验证：56 项单元测试、三种语言各 36 项 UI 检查、64 项完整 UI 检查和 176 项侧边栏检查通过。
适用于 Apple Silicon / macOS 13+。0.1.18 及以上版本可在应用内检查更新；0.1.17 及更早版本需手动安装。
