# AetherNotchQuota 0.1.35 · 绘本互动与集中设置

- 柔和绘本动画：小龟慢探、小狐蹭蹭、小幽灵害羞团团；摸摸后浮出小爱心。
- 新增原生偏好设置，集中管理外观、账号、提醒、更新及脱敏诊断。
- 可选低额度与恢复通知、账号静音、安静时段；默认关闭，首次读取不通知。
- 查询失败退避，尊重服务限流，保留旧数据和账号隔离。

支持 Apple Silicon、macOS 13 及以上。通过应用内“检查更新”升级，或下载安装 DMG。
