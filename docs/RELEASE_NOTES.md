AetherNotchQuota 0.1.21：八种可选卡通伙伴。

- 新增橘子小猫、枫糖小狐、糯米熊猫和冰蓝企鹅，保留小幽灵、奶油小兔、蜂蜜小熊与云朵团子。

- 官网角色图片更新为应用实际渲染图。

验证：50 项单元测试、164 项侧栏检查和 64 项 UI 检查通过。
适用于 Apple Silicon / macOS 13+。0.1.18 及以上版本可在应用内检查更新；0.1.17 及更早版本需手动安装。
