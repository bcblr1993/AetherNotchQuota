# 0.1.20 侧边栏菜单修复验证

2026-10-02，Apple Silicon 本机。

问题：侧边栏直接用右键事件的点击位置弹出菜单，靠屏幕边缘时没有由应用限制根菜单位置。现在使用来源窗口所在显示器的可见区域，按原生菜单的实际尺寸选择窗口内侧并限制位置，使用屏幕坐标弹出；详情窗口的设置入口共用此逻辑。

- `swift test`：50 项通过。菜单几何回归涵盖左右边缘、上中下位置、负坐标与垂直排列的显示器区域。
- `--sidebar-test`：144 项通过。使用本机 AppKit 实际菜单尺寸检查根菜单边界与各级菜单宽高，保留原有七种外观、悬停、拖动落点、隐藏恢复、提醒及停止动画回归。
- `--ui-smoke`：64 项通过，包含菜单尺寸、三种模式和临时隐藏恢复。
- `scripts/build-app.sh` / `scripts/check-release.sh`：0.1.20 arm64 包布局和签名结构检查通过。

本次改动仅在打开菜单时计算位置，不增加后台定时器、动画或额度查询。物理多屏全部组合仍需更多设备验收；本机窗口测试与偏移坐标单元测试不等同于全部显示器硬件组合测试。
